MIDGARD POV 0.9.0 BETA — Windows Steam edition

1. Extract the entire ZIP to a folder. Close Tribes of Midgard.
2. Double-click Install.cmd. Select your Steam game folder if it isn't detected.
3. Click Install / Update. Launch the game normally and enter a world.
4. Click Mod settings near the upper-right corner while the cursor is visible,
   or press Insert to open the menu. Choose First person or Third person.
5. Set your FOV, sensitivity, crosshair, graphics preset and inverted look.
   Settings save automatically. Save & return to game closes the menu.

Shortcuts (optional): F6 toggle camera; F7 diagnostics; middle mouse or F8 free/resume cursor;
F9 switch view; F10 crosshair; F11 graphics; Page Up/Down FOV;
Home/End sensitivity. Insert toggles menu. Escape closes the mod menu.

UPDATES: Open this same Install.cmd whenever you want to check for updates.
It downloads and verifies the current Lua mod files from GitHub main. If the
game is closed, an existing installation updates automatically. Settings and
saves are retained. A running game or edited mod files stop an update. Offline,
existing installs are kept; new installs can use the bundled package. Loader or
installer changes require downloading a newer release ZIP.

To uninstall: close the game, run Install.cmd and click Uninstall.
Saves, personal preferences, logs and update backups are retained.
No administrator access or Unreal Engine installation is normally needed.
Existing unrelated UE4SS/proxy files are never overwritten. The installer will
stop and explain a conflict; other mod-loader installations need manual merging.

This is an unofficial camera/aim/color-grading mod. The bundled loader is the
specific UE4SS build tested with the Windows Steam game. Game updates may need
a compatible loader. Custom weapon behavior and multiplayer require testing.
This package does not change Engine.ini or render distance. The development
PC's separate draw-distance tweak is not included.

UE4SS: https://github.com/UE4SS-RE/RE-UE4SS
